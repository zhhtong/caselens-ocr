# Security and sensitive-data reporting

Do not report security problems by uploading patient files, participant data, credentials, confidential protocols, proprietary software, or other sensitive material to a public issue.

## Reporting a vulnerability

If GitHub shows a **Report a vulnerability** button on this repository's Security page, use it to send a private report. Include the affected version, impact, minimal reproduction steps, and suggested mitigation without attaching sensitive source documents.

If private vulnerability reporting is unavailable, open a minimal public issue stating only that you need a private reporting channel. Do not include exploit details, credentials, sensitive logs, or private documents. The maintainer can then establish an appropriate private channel.

## Project boundary

CaseLens OCR is intended for local processing of synthetic or de-identified research documents. It has not been assessed as a medical device, clinical decision system, regulated production environment, or production-grade security system.
